# Password Generator

A simple Python script for generating secure random passwords.  
Great for learning Python basics and useful for cybersecurity beginners!

## Features

- Specify password length
- Includes uppercase, lowercase, numbers, and symbols
- Easy to use on the command line

## Usage

1. **Clone the repository:**
    ```bash
    git clone https://github.com/Mihai-Go/password-generator.git
    cd password-generator
    ```

2. **Run the script:**
    ```bash
    python3 password_generator.py
    ```

3. **Enter your desired password length when prompted.**

## Example Output

```
Enter password length: 16
Generated password: vW9!pQa3$LsBz&2x
```

## How It Works

- Uses Python's `random` and `string` modules to select random characters.
- Password includes letters, digits, and punctuation for extra strength.

## Learning Outcomes

- Working with Python modules (`random`, `string`)
- User input and output
- Basic function definition
